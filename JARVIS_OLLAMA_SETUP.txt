JARVIS - LOCAL OLLAMA ROUTING UPDATE
===================================
Built against the files you uploaded on September 21, 2026.

WHAT THIS UPDATE DOES
--------------------
Whisper still transcribes speech and Piper still speaks replies.
The current Actions parser gets the first chance to handle every command.
Only otherwise-unrecognized requests go to local Ollama (qwen2.5:3b).
The model returns a small validated intent object, not executable code.

Read-only interpretations, such as asking the current time in another way,
go through the existing handlers.

Interpreted changes, such as "get Notepad up for me", ask:
  I understood: open Notepad. Say confirm interpretation, or cancel.
Say exactly "confirm interpretation" to proceed.
Any existing app-choice, loud-volume or force-end confirmation still follows.

While ANY native choice, confirmation, or note dictation is pending, the model
is bypassed. The existing wake phrase, 15-second answer window, organizer
storage, timers and reminder announcements remain in the Whisper entry point.

This is an intent interpreter, not open-ended conversation or an autonomous
computer agent. Model-generated answers are not spoken as factual answers.
No weather, web search, music search, in-app automation, arbitrary scripts,
typing, file deletion, PC shutdown or restart are added.

LIMITS AND FALLBACKS
-------------------
Natural phrasing is supported only for the intents listed in jarvis_intent.py.
Exact commands still cover the larger existing command set, including maths,
date calculations, named timers, timer cancellation, and detailed organizer work.

The model is not used to rewrite note bodies, reminder bodies or calculations.
Use the original help examples for those commands.
"Take a note" may be paraphrased to start dictation, but a paraphrase containing
the note body is deliberately not supported.

Unrecognized requests send only that utterance and a fixed schema/prompt to:
  http://127.0.0.1:11434
The client disables proxies and redirects. It does not send your saved notes,
app catalogue or conversation history to the model.

The voice-loop wait is bounded to 30 seconds.
If a timer/reminder becomes due during model interpretation, the interpretation
is discarded and the alert takes priority. A late model response cannot run an
action. An old request may briefly still be finishing in its background thread.

For exact-command-only operation:
  .\.venv-whisper\Scripts\python.exe .\jarvis_whisper.py --no-ollama

Existing microphone-only dry run remains available:
  .\.venv-whisper\Scripts\python.exe .\jarvis_whisper.py --dry-run

Dry run does not open the organizer database, execute controls, OR call Ollama.
Use jarvis_intent.py --text for the separate no-action model test.
